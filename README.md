# Dr Mohith S — GitHub Pages

This is the static HTML/CSS conversion of the original Reflex project.

## Publish
1. Create a **public** GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Open the URL GitHub provides.

The site is static and does not require Python, Reflex, or a server.

## Notes
- Appointment and map buttons link to the external URLs used by the original project.
- Phone links use `tel:` and work on mobile devices.
- Google Fonts are loaded from Google Fonts; the site still renders with system/Georgia fallbacks if they are unavailable.
